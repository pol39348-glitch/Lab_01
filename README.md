# Toolkit

Консольный набор утилит на Python: калькулятор математических выражений и конвертер единиц измерения.

# Возможности

- Вычисление выражений с числами, скобками и операциями `+`, `-`, `*`, `/`.
- Перевод единиц длины: `mm`, `cm`, `m`, `km`.
- Перевод единиц массы: `g`, `kg`.
- Перевод температуры: `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвин).
- Проверка ошибок: некорректные выражения, неизвестные или несовместимые единицы, деление на ноль и температура ниже абсолютного нуля.

# Установка

Из корневой папки проекта установите пакет в режиме разработки:

```bash
pip install -e .
```

# Использование

Калькулятор запускается командой `toolkit calc`, после которой указывается выражение в кавычках:

```bash
toolkit calc "2 + 2 * 3"
```

Результат:

```text
8
```

Конвертер запускается командой `toolkit convert`: сначала указывается значение, затем исходная и целевая единицы:

```bash
toolkit convert 150 --from cm --to m
```

Результат:

```text
1.5
```

Пример перевода температуры:

```bash
toolkit convert 100 --from c --to f
```

Названия команд и единиц нечувствительны к регистру. При ошибке программа выводит сообщение в поток ошибок и завершает работу с кодом `2`.

# Как устроен код

# `__main__.py` — командная строка

Это точка входа программы. Модуль с помощью `argparse` разбирает команду и её аргументы. Для `calc` он передаёт выражение функции `calculate`, а для `convert` сначала преобразует введённое значение в число, затем передаёт его функции `convert`. Результат выводится в консоль.

Если возникает ожидаемая ошибка из набора `ToolkitError`, программа печатает её причину. Неожиданные ошибки также перехватываются, чтобы завершить работу с сообщением, а не с длинной трассировкой.

# `calculator.py` — вычисление выражений

Функция `calculate` обрабатывает выражение в несколько этапов:

1. `tokenize` убирает пробелы и разбивает текст на числа, операторы и скобки. На этом этапе проверяются недопустимые символы и некорректные числа.
2. `validate` проверяет наличие операндов в выражении.
3. Операторы и скобки преобразуются в порядок, учитывающий приоритет операций: умножение и деление выполняются раньше сложения и вычитания.
4. Полученная последовательность вычисляется с помощью стека чисел.

Такой порядок позволяет корректно вычислять выражения вроде `2 + 2 * 3` и учитывать скобки. Деление на ноль и некорректная структура выражения приводят к специальным ошибкам.

# `converter.py` — перевод единиц

Функция `get_group` определяет, к какой категории относится единица: длина, масса или температура. `convert` приводит названия единиц к нижнему регистру, проверяет их существование и совместимость.

Для длины и массы значение сначала переводится в базовую единицу категории, а затем из базовой единицы — в целевую. Температура обрабатывается отдельно: `convert_temp` сначала переводит её в Кельвины, проверяет абсолютный ноль, а затем вычисляет значение в целевой шкале.

Например, сантиметры переводятся сначала в метры, а потом в нужную единицу длины. Попытка перевести граммы в километры вызывает ошибку несовместимых единиц.

# `errors.py` — ошибки приложения

`ToolkitError` — базовый класс ошибок Toolkit. Остальные классы наследуются от него и обозначают конкретные проблемы: пустое или некорректное выражение, деление на ноль, неправильное числовое значение, неизвестную или несовместимую единицу измерения и температуру ниже абсолютного нуля. Благодаря общей базовой ошибке командный интерфейс может обработать все ожидаемые ошибки единообразно.

# `__init__.py` — пакет

Файл обозначает каталог `toolkit` как Python-пакет. Сейчас он пустой и не содержит дополнительной логики.
